# Security policy

## Supported version

Security fixes are accepted for the latest release of the App Store 2.3.3 branch.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** button in the repository's Security tab so details remain private
until a fix is ready. Do not open a public issue for vulnerabilities involving arbitrary code execution,
unsafe path handling, signature bypasses, injected-library loading, or destructive file operations.

Include the affected release, macOS version, reproduction steps, impact, and any suggested mitigation. Do not
attach game executables, saves, credentials, signing identities, or other private data.

This policy covers this repository's code. Game bugs and platform vulnerabilities should be reported to their
respective vendors.
