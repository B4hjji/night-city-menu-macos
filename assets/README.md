# Assets

- `icon.png` is the editable source artwork for the launcher icon.
- `AppIcon.icns` is the packaged macOS icon used by source and release builds.
- The screenshots and demo video are preserved from the upstream Steam 2.3.1 project for historical reference.
  They show older **CET Mac / NightCity Console** branding and should not be used to document the current App
  Store 2.3.3 interface without being replaced by fresh captures.
