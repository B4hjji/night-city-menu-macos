# Third-party components

Night City Menu bundles or builds against the following third-party software.
Each retains its own license. Night City Menu distributes **none** of CD PROJEKT RED's
game files - players use their own legally-owned copy of Cyberpunk 2077.

| Component | Role | License | Source |
|---|---|---|---|
| **Dear ImGui** | In-game console UI (Metal backend) | MIT | https://github.com/ocornut/imgui |
| **Frida (frida-gadget)** | In-process script host injected into the game | [wxWindows Library Licence 3.1](https://github.com/frida/frida/blob/main/COPYING) | https://github.com/frida/frida |
| **PUC-Lua 5.1.5** | Embedded Lua runtime used by the native overlay | MIT | https://www.lua.org/ftp/ |
